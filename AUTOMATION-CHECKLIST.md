# Automation Checklist

The portfolio build is designed around one Windows command:

```powershell
.\BUILD-GITHUB-PORTFOLIO.ps1
```

It should leave the public portfolio in this state:

- cybersecurity/SOC-first positioning
- approved project set only
- DBD261 excluded
- raw academic records excluded
- required project documentation present
- obvious credential patterns rejected
- Git changes committed and pushed when credentials permit
