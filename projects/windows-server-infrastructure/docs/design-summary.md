# Hybrid Windows Infrastructure — Design Summary

**Module:** OPS261 — Operating Systems 261

## Scenario

A simulated EduTech environment requiring a Windows Server 2019 domain infrastructure with remote access, security hardening and hybrid identity planning.

## Architecture areas covered by the project

- Active Directory Domain Services
- DNS
- DHCP
- File Services / DFS
- Group Policy
- Remote Desktop Services
- VPN / DirectAccess planning
- Windows Server Backup and monitoring
- Security hardening
- Certificate Services
- Azure AD / hybrid identity planning

## Portfolio value

This is strong infrastructure evidence because it connects identity, networking, administration and security rather than treating them as isolated technologies.

## Security angle

The most relevant areas for a future SOC/cloud-security path are identity and access control, Group Policy, certificate services, authentication, logging and hybrid identity.
