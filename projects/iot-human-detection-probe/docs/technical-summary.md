# Technical Summary

The IOT261 Human Detection Probe project proposed a search-and-rescue device for post-earthquake environments.

## Core idea

A PIR sensor detects changes in infrared energy associated with human presence and triggers an audio/visual indication.

## Engineering themes

- embedded sensing
- microcontroller integration
- alerting
- system constraints
- disaster-response problem solving

## Portfolio value

This project demonstrates hardware-aware systems thinking beyond conventional software development and infrastructure work.
