# Human Detection Probe

**Module:** IOT261 — Internet of Things  
**Focus:** Arduino, PIR sensing, embedded design

## What this project demonstrates

A technical design for a human-detection probe intended for post-earthquake search and rescue. The documented design uses a PIR sensor to detect changes in infrared energy and trigger an audio-visual alert.
