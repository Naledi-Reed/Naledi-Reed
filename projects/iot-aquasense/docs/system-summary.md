# AquaSense System Summary

**Module:** PMM261 — Project Management 261

## System concept

AquaSense is a proposed smart irrigation and environmental monitoring system combining sensors, a microcontroller, networking, cloud services and a user-facing application.

```text
Sensors
  ↓
Microcontroller
  ↓
Network
  ↓
Cloud services
  ↓
User-facing application
```

## Project evidence

The supplied project material covers scope, objectives, work breakdown, scheduling, dependencies, risks, monitoring and integration planning.

## Security/cloud evolution

A technical implementation could later add authentication, access control, secure messaging, infrastructure as code, monitoring and CI/CD.
