# AquaSense - IoT Smart Irrigation & Environmental Monitoring

**Module:** PMM261 - Project Management 261  
**Focus:** IoT systems, project planning, cloud-enabled monitoring

## Concept

AquaSense is a proposed IoT-based smart irrigation and environmental monitoring system for small farms and residential agricultural environments.

The project combines sensor technology, microcontrollers, cloud computing and a user-facing application to support irrigation decisions and crop health.
