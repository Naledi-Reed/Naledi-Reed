# SQL Server Project Allocation Database

**Module:** DBD261 - Database Development 261  
**Focus:** SQL Server, T-SQL, relational modelling

## The problem

A technology and innovation company needs to manage departments, employees and projects, including which employees are allocated to which projects.

## Data model

The academic design uses a relational structure centred on:

`DEPARTMENTS -> EMPLOYEES -> PROJEMPS <- PROJECTS`

The `PROJEMPS` relationship represents employee/project allocation.

## Technical evidence

The coursework covers:

- Database creation in SQL Server
- T-SQL implementation
- Project and employee data structures
- Relational relationships
- Database diagramming

## Why it belongs here

DevSecOps work still depends on understanding data. This project shows the database layer behind the infrastructure and application layers.
