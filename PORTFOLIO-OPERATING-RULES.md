# Portfolio Operating Rules

## Public GitHub

Publish:
- source code
- sanitized reports
- diagrams
- screenshots
- project READMEs
- demos
- learning notes

Avoid publishing:
- student numbers
- private contact details
- lecturer/private correspondence
- raw marks
- credentials/API keys
- other students' personal information
- proprietary course material that you do not have permission to redistribute

## Every project README should answer

1. What was the problem?
2. What did I build/do?
3. What technologies were involved?
4. What went wrong or was difficult?
5. What was the result?
6. What did I learn?
7. How can someone reproduce or inspect it?

The portfolio should make a recruiter understand your contribution in under two minutes.
